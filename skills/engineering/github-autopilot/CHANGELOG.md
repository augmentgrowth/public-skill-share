# Changelog — github-autopilot
[2026-08-18] v1.2.1 — Recovery-tag retention raised from 30 to 90 days. At 30 the `autopilot/trash/*` tag expired in lockstep with the reflog it exists to replace, so it added no time over the fallback it was meant to improve on. The tags are local-only refs of a few dozen bytes covering the riskier deletion class (content-proven, not ancestry-proven), so a long window is close to free. Nothing automates the prune — it is agent guidance in the sweep — which is another reason not to set it tight.

[2026-08-18] v1.2.0 — Hygiene sweep now disposes instead of describing. The sweep previously acted only on refs already dead (`[gone]` upstreams, `prunable` worktrees) and merely reported every other class; reporting is a no-op when nothing consumes the report, so debt accumulated in exactly the classes the sweep inspected every run. Added: remote-only branch enumeration (`git branch -r`), with `remote_ref` and `short_name` bound separately since substituting one for the other fails silently in both directions; worktree-pinned merged-branch release, with an executable dirt-adjudication sequence (worktree removal must precede branch deletion, and a worktree whose directory exists is never `prunable`); a tag-based disposal ladder for `backup|archive|rescue` branches — contained → already-tagged → tag-verify-then-delete — replacing the blanket "never delete autonomously", reconciled with safety-boundaries.md; a stale open-PR sweep with a single decision order and verified content preservation before any close; post-merge remote-ref verification, since `--delete-branch` is a local git call that fails independently of the API merge; and an encrypted-at-rest carve-out on the secrets stop condition.

[2026-07-21] v1.1.0 — Ported the 2026-07-21 audit pass from the production skill. Containment Verification ladder (ancestry → merged-PR headRefOid → merge-tree tree-equality) with autopilot/trash recovery tags replaces ancestry-only checks (squash merges blind git branch --merged). Stop guard: empty no-upstream branches no longer flagged. Watchdog: tier stderr preserved in report + leftovers; squash-aware gone-branch classification; stale-WIP aging (content fingerprint, WIP_STALE_DAYS, escalates only unchanged dirty checkouts — never auto-commits); dry-run can no longer clobber a real report; rolling LEDGER.md. SKILL.md: checkpoint-commit guidance, Gotchas section. Evals: +2 credential routing cases; new run-model-routing.sh (model-in-the-loop routing eval, needs authenticated claude CLI).
[2026-07-15] v1.0.0 — Initial public release. Router SKILL.md + references (pr-owner, ci-repair, review-feedback, merge-conflicts, branch-hygiene, credentials, decision-policy, safety-boundaries, repo-profile pattern), optional Stop-hook closeout guard, optional daily three-tier hygiene watchdog, structural eval checks.
